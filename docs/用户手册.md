## 三分钟上手

1. 去 [Releases](https://github.com/konka0812/scout-cat/releases/latest) 下载安装版或便携版
2. 双击打开（Windows 会提示「未知发布者」，点「仍要运行」）
3. 按引导页填一个 API Key，点「搞定」
4. 把猫拖到屏幕角落，让它自己巡逻

之后什么都不用管：它按你设的频率上网找东西，觉得值得你知道就弹个气泡，
其余的都放进背包等你翻。

## 安装

### 下载

| 文件 | 说明 | 选哪个 |
|---|---|---|
| `scout-cat-<版本>-win.exe` | 安装版 | 大多数人 |
| `scout-cat-<版本>-portable.exe` | 便携版 | 想放 U 盘、不想装进系统 |

两者功能完全一样。

### 关于「未知发布者」提示

安装包**没有代码签名**，所以 Windows SmartScreen 会拦截一次：

- 蓝色框「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」
- 这是个人项目的正常现象，不是病毒

要彻底消除提示需要购买代码签名证书（每年几百美元），目前没做。

### 系统要求

- Windows 10 1809 或更新版本（64 位）
- 能访问 DeepSeek 的接口地址

## 第一次运行

打开后会看到一个引导页，四步：

### 第 1 步：给宠物起个名字

默认叫「猎猫」，可以随便改。名字会显示在托盘和设置里。

### 第 2 步：选你关注什么

点选即可，可以多选。预设了六个常见方向：

`AI 工具` · `AI 视频` · `开源项目` · `产品更新` · `AI 编程` · `设计工具`

这些关键词会用来生成搜索查询。后面在「设置 → 兴趣与屏蔽」里随时能改。

也可以点「自定义兴趣」，回车添加自己的关键词。

### 第 3 步：填 API Key

| 字段 | 填什么 |
|---|---|
| API Base URL | 默认 `https://api.deepseek.com/v1`，用 DeepSeek 就不用改 |
| API Key | 你的 Key |
| 模型 | 默认 `deepseek-chat` |

填完点「测试连接」，看到连通性正常再继续。

> 也可以用任何 **OpenAI 兼容**的接口，把 Base URL 换成你自己的服务商地址即可。

### 第 4 步：完成

点「搞定」，猎猫开始定时巡逻。第一次会往前回看 **48 小时**，
挑少量结果放进背包，不会一口气弹几十条。

## 桌宠怎么用

### 拖动

**按住猫不放，直接拖**。拖到想放的位置松手即可。

> 注意：只有**点在猫身上**才拖得动。点在猫周围的空白区域是拖不动的——
> 那是故意做的「点击穿透」，防止猫挡住你后面的窗口。

### 双击猫

打开**发现背包**。

### 右键猫

打开**设置**。

### 单击猫

猫会做个被摸的表情动作，纯好玩。

### 托盘菜单

右键点击任务栏右下角托盘里的猫头图标：

| 菜单项 | 作用 |
|---|---|
| 打开发现背包 | 同双击猫 |
| 设置 | 同右键猫 |
| 立即查找一次 | 立刻巡逻一轮（不用等定时） |
| 宠物 | 手动播某个动作：待机 / 巡逻 / 发现 / 报信 / 睡觉 |
| 退出 | 退出程序 |

左键单击托盘图标 = 打开背包。

## 气泡提醒

气泡就是猫头顶冒出来的那个白色小卡片，写着一条发现的标题和简介。

### 什么时候会弹

- 巡逻找到**值得提醒**的新发现 → 弹一条
- 背包里还有**未读**条目 → 按间隔**持续轮播**（一条接一条）

气泡默认停留 **30 秒**，可以点一下直接跳到原文。

### 为什么这次没弹

程序会先过一遍规则，不满足就只进背包不弹窗：

- **免打扰时段**（默认 22:00–08:00）
- **每日弹气泡已达上限**（默认 3 条）
- **每月提醒已达上限**（默认不限）
- **当前处于全屏/专注状态**

被拦下来的会进入**积压队列**，等你退出全屏或第二天额度刷新后优先补弹。

### 气泡一直弹个不停？

因为「未阅轮播」开着。只要背包里还有未读条目，它就会一条接一条地轮播。

想停的话，两个办法：

1. 把背包里的条目标记为**已阅**（或点「全部已阅」）
2. 到「设置 → 高级设置」关掉「未读轮播」

### 气泡宽度为什么不变？

气泡宽度是**固定 250px**，不会跟着猫一起放大。
这样气泡不会因为猫变大而把桌宠挡住。猫的大小和气泡大小是独立的两回事，
分别在「设置 → 宠物外观」和「设置 → 高级设置」里调。

## 发现背包

双击猫打开。猎猫带回来的东西都在这儿。

### 三个页签

| 页签 | 内容 |
|---|---|
| **新发现** | 所有还没处理的条目 |
| **已收藏** | 你点过「收藏」的 |
| **待核实** | 证据不足、日期缺失，没敢直接推给你的 |

### 每条发现长什么样

```
● devops-exercises — GitHub 今日热榜
  汇集大量运维与开发练习题的资源库，涵盖系统管理、容器、
  云服务与自动化工具，适合备考与动手练习。
  github.com
  消息 1 天前 · 搜到 1 天前
  [打开原文] [收藏] [少看这类] [删除]
```

- **标题**前面的圆点 = 未读标记，已读后消失
- **简介**是模型写的一句话中文概述，不是原文复制
- **消息时间** = 这条内容本身发布的时间
- **搜到时间** = 猎猫什么时候发现它的

两个时间分开标，是因为搜索经常捞到几天前的旧内容，
你能一眼看出"这是旧闻还是刚发的"。

### 四个操作

| 按钮 | 作用 |
|---|---|
| **打开原文** | 用默认浏览器打开链接，并自动标记为已读 |
| **收藏** | 收藏起来；同时告诉程序"这个来源我喜欢"，以后多推这类 |
| **少看这类** | 屏蔽这个来源和链接；以后不再推同类 |
| **删除** | 从背包删掉（见下面的说明） |

### 批量操作

| 按钮 | 作用 |
|---|---|
| **全部已阅** | 所有条目标记已读（不删内容） |
| **删除已阅** | 删掉所有已读条目，有确认提示 |
| **清空** | 清空全部发现，有确认提示 |

右上角会显示「未读 N」。

### 删掉之后会不会再推？

**会。** 这是故意设计的：删除 = 告诉程序"我没看过这条"。
那条链接重新可用，下次巡逻搜到还会再推一次。

如果你只是不想再看到某类内容，应该用**「少看这类」**，而不是删除。

## 去重：为什么不会重复烦你

背包（`discoveries`）是程序**唯一**的"已看过"账本。判断规则很简单：

| 情况 | 结果 |
|---|---|
| 背包里**已有**这个 URL，内容指纹没变 | 跳过，不打扰你 |
| 背包里**没有** | 当新发现 |
| 背包里**有**，但内容指纹变了（实质新进展） | 当新进展，可以再提醒一次 |
| 模型判定是**重复报道**，但 URL 都不在背包里 | 照样推出（不拿内部历史拦你删掉的东西） |

几个实际场景：

- **同一篇新闻被十个网站转载** → 只推一次（批内去重 + 标题相似合并）
- **某个工具今天发了新版本** → 内容指纹变了，会再提醒你一次
- **你把某条删了** → 它重新可用，会再推（见上一节）
- **搜索失败** → 状态栏显示错误，**不会**假装"没有新消息"

## 设置逐项说明

打开方式：右键猫 → 设置，或托盘菜单 → 设置。

### 巡逻状态

只读，显示当前状态：

| 字段 | 含义 |
|---|---|
| 状态 | 正常 / 查找中 / error / 已暂停 |
| 上次运行 | 上次巡逻的时间 |
| 全屏/专注 | 是否正在全屏（全屏时不弹窗） |
| 积压气泡 | 排队等着弹的条数 |
| 错误 | 失败原因（比如额度不足） |

下面两个按钮：**刷新**（重新拉一次状态）、**立即巡逻一次**。

> 如果状态显示 `已暂停` 并且错误里提到额度 / 登录，
> 说明 Key 余额不足或失效，改完 Key 重新保存即可恢复。

### 基本

| 项 | 默认 | 说明 |
|---|---|---|
| 宠物名字 | 猎猫 | 显示在托盘和设置里 |
| 检查频率（分钟） | 60 | 每隔多久巡逻一次 |
| 每日最多弹气泡（条） | 3 | `0` = 不限；达到后进背包不弹窗 |
| 搜索范围 | 只看今天 | 也可选「近 7 天」 |
| GitHub 每次推荐几个 | 3 | 每次从今日热榜推荐几个仓库 |
| 每次巡逻推荐 GitHub 热榜项目 | 开 | 关掉就不推荐了 |

### 高级设置

| 项 | 默认 | 说明 |
|---|---|---|
| 开机自动启动 | 关 | |
| 气泡显示时长（秒） | 30 | 气泡停留多久 |
| 未读轮播间隔（秒） | 2 | 上一条气泡消失后隔多久接下一条 |
| 每月提醒上限 | 0（不限） | |

### 兴趣与屏蔽

- **关注兴趣**：回车添加关键词，影响搜索查询和 GitHub 推荐打分
- **屏蔽主题**：回车添加，搜索时排除

### 免打扰

- 勾选「启用免打扰时段」
- 默认 `22:00` – `08:00`
- 支持跨午夜（开始时间大于结束时间时会自动按跨天处理）
- 该时段内不主动弹气泡

### 接口

| 字段 | 说明 |
|---|---|
| Base URL | OpenAI 兼容接口地址 |
| API Key | 你的 Key |
| Model | 模型名 |
| Search Base URL | 搜索服务地址 |
| 连通性 | 点「重新检测」验证 |

### 高级搜索参数

| 项 | 默认 | 说明 |
|---|---|---|
| 每次查询数 | 3 | 一次巡逻发几条搜索查询 |
| 单次 Fetch 上限 | 6 | 最多抓取多少个网页正文 |
| 事件保存（天） | 30 | 内部历史事件保留多久 |
| 模型 JSON Output | 开 | 让模型返回结构化 JSON，解析更稳 |

### 偏好反馈

**只读**。收藏和「少看这类」会自动记录在这里，
用来调整后续的搜索和推荐方向。

### 待核实

显示有多少条「证据不足」的候选，可以一键清空。

### 宠物外观

- **缩放**：小 (0.5×) / 标准 (1×) / 大 (1.5×) / 特大 (2×)
- **测试动作**：选一个动作，点「播放」看看效果

> 缩放调大后如果觉得太大，重新打开设置改成小一点的档即可，
> 拖回去或重启程序也会应用新尺寸。

## 提醒规则：什么时候弹、什么时候不弹

一次巡逻结束后，程序按这个顺序决定要不要打扰你：

```
找到新发现
  ↓
今天弹过几条？  ── 达到每日上限 ──→ 进积压队列（恢复后优先补弹）
  ↓ 没达到
这个月在提醒上限内吗？ ── 超了 ──→ 进积压队列
  ↓ 没超
现在在免打扰时段吗？ ── 是 ──→ 进积压队列
  ↓ 不是
当前全屏/专注吗？ ── 是 ──→ 进积压队列
  ↓ 不是
弹气泡 ✅
```

**一次只弹一条。** 同一次巡逻找到的其他发现，全部进背包等你自己看。

### 巡逻时猫在干嘛

| 情况 | 动作 |
|---|---|
| 正在巡逻 | 行走 |
| 找到值得提醒的 | 发现 |
| 巡逻成功但没有新消息 | 睡觉 |
| 搜索失败 | 睡觉 + 弹一条错误提示 |
| 额度/登录失效 | 暂停调度 + 弹提示 |

## 常见问题

**Q：气泡弹出来的内容能信吗？**
简介是模型根据抓到的网页正文写的**概述**，不是原文。
拿不准就点「打开原文」自己看。证据不足、日期缺失的会被放进「待核实」，
不会主动弹给你。

**Q：会不会漏掉重要消息？**
如果消息发布时间超出你设的搜索范围（默认只看今天），就不会被推。
想覆盖更长时间可以改成「近 7 天」。
另外每次巡逻会适当往前回看，避免漏掉延迟收录的内容。

**Q：为什么有时候搜到的是几天前的旧闻？**
搜索服务返回的结果不一定都是当天的。每条发现都标了「消息时间」和「搜到时间」，
一看就知道。

**Q：猫卡住不动了 / 没反应？**
到设置里看「巡逻状态」。如果是 `error`，下面会写原因。
常见就是网络问题或 Key 余额不足。

**Q：换了 Key 还是报错？**
在「设置 → 接口」点「重新检测」确认连通性。
如果提示额度或登录失效，程序会自动暂停巡逻，改好 Key 保存后会恢复。

**Q：能不能只让它推荐 GitHub 项目，不搜新闻？**
可以。把「关注兴趣」清空，关掉搜索相关的量；
「GitHub 每次推荐几个」调大即可。

**Q：两台电脑能用同一个 Key 吗？**
能。Key 是各自本地保存的，互不干扰。

**Q： macOS 能用吗？**
目前只验证了 Windows。

## 数据与隐私

### 数据存在哪

全部在本机这一个文件里：

```
%APPDATA%\scout-cat\config.json
```

里面包含：

- 你的 API Key
- 背包条目（你看过什么）
- 巡逻状态、通知记录
- 关注兴趣 / 屏蔽词

### 会不会上传

**不会。** 这个文件不进 Git 仓库，程序也不会把它发到任何服务器。
所有网络请求都是你的机器**直接**发往你自己填的 Base URL。

### 想彻底清掉数据

退出程序 → 删除 `%APPDATA%\scout-cat\config.json` 即可。

### Key 的成本

搜索和摘要都会产生调用费用，具体看你用的服务商。
程序有每日 / 每月提醒上限，可以帮你控制频率。

---

## 卸载

**便携版**：直接删掉那个 exe 文件，然后删 `%APPDATA%\scout-cat\config.json`。

**安装版**：

1. 设置 → 应用 → 已安装的应用 → 找到「情报猎猫」→ 卸载
2. 删除 `%APPDATA%\scout-cat\config.json`（如果不想留数据）

卸载**不会**自动删除 `config.json`，所以卸载后你的背包和设置还在，
下次装回来还能接着用。想彻底清干净就手动删掉那个文件。
